# Gathbandhan Kursi Race — build 1.1

A browser-based 2.5D/3D political King-of-the-Hill arcade prototype.

## Run
```bash
npm install
npm run dev
```

## Vercel
Import the GitHub repository. Framework preset: **Vite**. Build command: `npm run build`. Output directory: `dist`.

## Included in this build
- More detailed procedural Parliament arena, audience tiers, banners, spotlights and atmospheric particles
- More expressive stylized procedural characters
- Central VIP throne with capture-zone ring and ownership lighting
- Physical approach-and-sit capture pose while holding the throne
- 30-second coalition scoring, contested state, push and dash
- Responsive HUD and touch controls

This remains a procedural-art prototype: it does not yet include bespoke scanned/hand-modelled GLB characters, professional motion-captured animation, voice acting, or online multiplayer. Replace procedural characters and environment with original/licensed GLB assets in a later art-production phase.
